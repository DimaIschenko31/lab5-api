## Модель

Метод золотого перерізу (5-й семестр) — знаходження мінімуму функції `f(x) = x + 2/x` на відрізку `[a, b]`.

## Запуск

```bash
pip install flask
python app.py
```

## Endpoint

### GET /calculate

Параметри передаються через URL:

| Параметр | Тип | За замовчуванням | Опис |
|----------|-----|-----------------|------|
| `a` | float | 0.5 | Ліва межа відрізку |
| `b` | float | 2.0 | Права межа відрізку |

### Приклади запитів

```bash
curl "http://127.0.0.1:5000/calculate?a=0.5&b=2.0"
curl "http://127.0.0.1:5000/calculate?a=1.0&b=5.0"
```
